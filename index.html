Tabela Periódica das Skills do Claude

Cada elemento é uma skill: um pacote de instruções que o Claude carrega quando a tarefa pede. Toca num elemento para ver o que faz e a frase que a ativa. A estrela marca as essenciais para começar.

    Escolhe um elemento da tabela.

    Origem: Anthropic são as skills oficiais (as de ficheiros vêm ativas no Claude.ai; as restantes estão no repositório anthropics/skills). Plugin vem de pacotes instaláveis (engenharia e jurídico da Anthropic; SEO de terceiros). Tua é uma skill criada à medida com o Skill Creator. Comunidade são as mais recomendadas entre agosto e outubro de 2026; a maioria foi pensada para o Claude Code, mas qualquer uma pode ser carregada no Claude.ai como ZIP. Skills podem executar código: lê o SKILL.md antes de instalar uma de fonte desconhecida.
